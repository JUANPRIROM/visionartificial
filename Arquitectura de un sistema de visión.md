- Un sistema de visión se compone de una cadena de bloques funcionales, no solo la cámara
- Bloques principales: Iluminación ---> Óptica/Lente ---> sensor de imagen ---> Interfaz de adquisición ---> unidad de procesamiento ---> Salida/actuador.

Cada bloque impacta directamente la calidad del resultado final; un error en iluminación no se corrige después en software.


- Analizar un sistema embebido implica evaluar 3 dimensiones: el ambiente, los operadores disponibles y el proceso de generación de la aplicación

El ambiente de desarrollo es el conjunto de herramientas para programar, compilar, depurar y desplegar en el sistema embebido.
